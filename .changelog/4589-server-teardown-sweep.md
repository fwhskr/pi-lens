- Add a `test-server-teardown` ratchet sweep for #4589: a test that starts a real listener reds unless the close promise is proven settled where the hook actually runs it — in a teardown hook, a `finally`, the start's own function, or a local helper that returns it and whose every call site settles it. `await xs.forEach(...)`, `await xs.map(...)`, `Promise.race`, a helper that drops the promise, and an `await` in a function, callback, or branch the hook never runs all report instead of passing. A `bind`/`serve` start on a socket or runtime handle is in the population, including the computed `socket["bind"](0)` spelling and a runtime global's own `serve`; a verb, receiver, or construction the scan cannot read is reported as `unresolvable`, never counted clean. The sink drain sweep attributes a sink path at every parameter position of a same-file helper and judges the read where it runs against the call site that supplied the sink, so a helper that suspends on its own path before the read voids the caller's drain, and one that never runs that await does not.
